# Contract: assets-manifest.json Schema

**Branch**: `001-science-narrator`
**Date**: 2026-03-22

Written to `output/<run_id>/assets-manifest.json` by `validate_manifest.py` upon
successful compliance verification.

## JSON Schema

```json
{
  "run_id": "string (UUID)",
  "paper_id": "string (e.g. arxiv:2401.00001)",
  "generated_at": "string (ISO 8601 datetime)",
  "all_verified": "boolean",
  "assets": [
    {
      "asset_id": "string (UUID)",
      "type": "image | audio | background_music",
      "source": "dalle3 | gtts | openai_tts | royalty_free | public_domain",
      "source_url": "string (empty if AI-generated)",
      "generation_prompt": "string (empty if not AI-generated)",
      "licence": "string (e.g. openai-tos-commercial, cc0, pexels-licence, pipeline-generated)",
      "verified": "boolean (must be true)",
      "created_at": "string (ISO 8601 datetime)",
      "file_path": "string (path at time of export)"
    }
  ],
  "video_files": [
    {
      "format": "vertical_9_16 | horizontal_16_9",
      "width_px": "integer",
      "height_px": "integer",
      "duration_sec": "number",
      "file_path": "string",
      "exported_at": "string (ISO 8601 datetime)"
    }
  ]
}
```

## Approved Licence Values

| Value | Description |
|---|---|
| `openai-tos-commercial` | AI-generated by OpenAI (DALL·E 3 or TTS); commercial use permitted |
| `pipeline-generated` | Generated by gTTS (Google Translate TTS); no third-party copyright |
| `cc0` | Public domain / Creative Commons Zero |
| `cc-by-4.0` | Creative Commons Attribution 4.0 |
| `pexels-licence` | Pexels royalty-free licence (commercial reuse permitted) |
| `unsplash-licence` | Unsplash licence (commercial reuse permitted) |
| `pixabay-licence` | Pixabay content licence (commercial reuse permitted) |

Any other value causes `validate_manifest.py` to exit with code 1.

## Invariants

- `all_verified` MUST equal `true` for the pipeline to succeed.
- Every entry in `assets` MUST have `verified: true`.
- `video_files` MUST contain exactly two entries: one `vertical_9_16` and one `horizontal_16_9`.
